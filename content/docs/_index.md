MagicAF is a Rust framework, built by [Intracav](https://intracav.ai/), for AI systems that have to run where the data lives — on your servers, on isolated networks, and on devices. It is a workspace of {{< stat "crates" >}} crates: retrieval pipelines, an agent loop with tools and MCP, document ingest, model routing, calibrated on-device decisions, and the artifact format that lets a model describe an interface. Every capability is a trait, so each service is something you choose and host.

## Built on MagicAF

[Lumen](https://docs.intracav.ai), Intracav's clinical assistant, is built on MagicAF: its server uses the retrieval, routing, ingest, knowledge, and research crates, and its apps render `magicaf-ui` artifacts with [Lumen UI](/docs/lumen-ui/). The [Lumen docs](https://docs.intracav.ai) show the finished product from a user's side; [Lumen models](/docs/lumen-models/) describes how it serves its model family on MagicAF.
