## Not building a retrieval pipeline?

MagicAF is more than RAG. Start from the crate that fits what you are building:

- **An agent host** — [`magicaf-agent`](/docs/crates/magicaf-agent/) runs the turn loop; [`magicaf-tools`](/docs/crates/magicaf-tools/) and [`magicaf-mcp`](/docs/crates/magicaf-mcp/) give it tools.
- **A mobile or desktop client** — [`magicaf-mobile`](/docs/crates/magicaf-mobile/) adds on-device text helpers with no model and no network.
- **Interfaces generated by a model** — [`magicaf-ui`](/docs/crates/magicaf-ui/) defines the artifact format that [Lumen UI](/docs/lumen-ui/) renders.
- **Calibrated yes/no decisions on the device** — [MagicAF Reflex](/docs/reflex/).

The [crate catalog](/docs/crates/) lists all {{< stat "crates" >}}.
