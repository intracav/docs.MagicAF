Built For Rooms Without Internet

Air-gapped is the default, not an afterthought.

The core services talk only to servers you run. Models, dependencies, and data can all live on your side of the wall — for hospitals, labs, and networks where data cannot leave the building.

Only the endpoints you configure

No telemetry, no update check, no license server. The core services talk to embedding, vector, and model servers you run; anything that reaches a hosted API is something you construct on purpose.

Vendorable dependencies

cargo vendor captures every crate, MagicAF included, for an offline build. The air-gapped guide covers the toolchain, images, and model weights too.

Secrets stay secret

API keys are SecretString values, never serialized or logged; audit events carry a hash of the query, not its text. See the security guide.

Built On MagicAF

Interfaces a model can write.

Lumen, Intracav's clinical assistant, runs on MagicAF. Its models describe charts, forms, timelines, and clinical cards in the magicaf-ui artifact format, and Lumen UI renders them live as the tokens arrive.
