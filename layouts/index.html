Built For Rooms Without Internet

Air-gapped is the default, not an afterthought.

Every service assumes a local endpoint. Models, dependencies, and data all live on your side of the wall — for hospitals, labs, and networks where data cannot leave the building.

No outbound calls

All processing happens against endpoints you configure. There is no telemetry, no phone-home, no cloud SDK in the dependency tree.

Vendorable dependencies

Every dependency can be vendored for offline builds. The air-gapped deployment guide walks through the whole procedure.

Secrets stay secret

API keys and sensitive configuration are never serialized or logged. See the security guide for the hardening checklist.
