# MagicAF

> MagicAF is the open-source Rust AI/ML/NLP framework by **Intracav**. It provides the foundational building blocks for AI systems — embeddings, vector search, LLM orchestration, RAG pipelines, and a full NLP toolkit — with zero cloud dependencies. Air-gapped-capable and built for on-premises deployment: designed for hospitals and other environments where data cannot leave the network. It is the framework underneath Lumen, Intracav's clinical AI platform, and this site also documents **Lumen UI**, the component DSL that renders Lumen's AI-generated interfaces.

## How to use this file

This is the structured index of magicaf.intracav.ai for AI agents — Claude, ChatGPT, Gemini, Perplexity, and the like. Every URL here is canonical and citable. Source code lives at https://github.com/magicaf/magicaf.

Three machine-readable formats are available:

- **This file** ({{ $base }}/llms.txt) — the index: every page on the site with a one-line description.
- **{{ $base }}/llms-full.txt** — the entire documentation corpus as a single Markdown document ({{ $pageCount }} pages). Use this when you want the whole thing in one fetch.
- **Per-page Markdown** — append `index.md` to any page URL for clean Markdown without site chrome. Example: `{{ $base }}/docs/getting-started/quickstart/index.md`. Every HTML page also advertises this via `<link rel="alternate" type="text/markdown">`.

Crawling is explicitly permitted for AI agents — see {{ $base }}/robots.txt and {{ $base }}/.well-known/ai.txt.
